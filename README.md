# 📊 Customer Behaviour Analysis

![Customer Behaviour](assets/customer_behavior_banner.png)

## 📌 Project Overview

Customer Behaviour Analysis focuses on understanding how customers interact with products and services by analyzing purchasing patterns, repeat purchases, and decision-making factors.  
This project analyzes customer data to uncover insights related to **buying patterns, repeat purchases, discounts, reviews, seasonal trends, and payment preferences** using **Python, SQL, and Power BI** to enable data-driven business decisions.

---

## 📂 Dataset Description

![Dataset Overview](assets/dataset_overview.png)

The dataset represents structured customer transaction data and includes:

- 🧾 Customer and transaction attributes  
- 💸 Discount and promotional details  
- 💳 Payment method preferences  
- ⭐ Customer reviews and ratings  
- 🔁 Purchase frequency and repeat behavior  
- 📅 Seasonal and time-based trends  

---

## 🔍 Key Analysis Areas

![Key Analysis](assets/analysis.png)

- 🛒 Customer buying patterns  
- 🔁 Repeat vs one-time customers  
- 💰 Impact of discounts on purchasing decisions  
- ⭐ Influence of reviews and ratings  
- 📊 Seasonal demand trends
